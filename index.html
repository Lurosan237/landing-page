03 · how I work

Three habits I bring to every project.

01Self‑taught: I learn what the problem needs+
Nobody taught me to code. I started on Khan Academy, then learned from docs, papers, source code and a lot of trial and error. That's how I picked up Raft, Flink, calibration, PDF font internals, zero‑knowledge proofs and 3D reconstruction, each one because a project needed it.
02Think like a mathematician+
Maths taught me to state exactly what should be true, then check it. Every project comes with a baseline, a held‑out test and a written report. I don't call anything "fast" or "accurate" until I've measured it, and I publish the results even when they're unflattering.
03Anyone can try it+
My demos run live in the browser, with nothing to install and no account. If someone can't try it in a minute, I don't consider it finished.
